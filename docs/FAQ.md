# Частые вопросы

Команды ниже для Docker: `docker exec mihomyak mihomyak <команда>`. Без Docker —
просто `mihomyak <команда>`.

### Как понять, что всё работает?

```sh
docker exec mihomyak mihomyak status        # подписка, трафик, выбранные узлы, mihomo
docker logs --tail 50 mihomyak
```

Для шлюза — проверка изнутри подключённого контейнера:

```sh
docker exec my-app curl -s https://ifconfig.me     # IP должен быть IP VPN-узла
docker exec my-app nslookup example.com            # адрес 198.18.x.x — DNS идёт через mihomo
```

### Панель пишет «лимит устройств»

У провайдера занято максимальное число устройств. Каждый новый HWID — новое
устройство:

- смена `MIHOMYAK_CLIENT` меняет HWID (у каждого клиента своя формула);
- потеря тома `/data` без `MIHOMYAK_DEVICE_SEED` даёт новый HWID;
- два сервера без общего seed — это два устройства.

Задайте постоянный `MIHOMYAK_DEVICE_SEED` и удалите лишние устройства в боте или
кабинете провайдера. `mihomyak identity` покажет текущий HWID. Рабочий конфиг при
отказе панели не трогается.

### Провайдер пишет, что платформа или приложение не поддерживается

Некоторые провайдеры пускают только определённые приложения. Попробуйте другого
клиента: `MIHOMYAK_CLIENT=koala` или `happ` (это новое устройство, см. выше).
`mihomyak fetch --client happ` покажет ответ панели, ничего не применяя.

### Шлюз не стартует: «Docker resolves names … outside the tunnel»

У сервиса `mihomyak` нет `dns:`. Без него DNS приложений шёл бы мимо VPN, поэтому
шлюз отказывается работать. Верните `dns: [1.1.1.1, 8.8.8.8]` в compose-файл
([подробнее](DOCKER.md#dns-почему-у-шлюза-обязателен-dns)).

### После перезапуска шлюза у контейнеров пропал интернет

Перезапущенный шлюз получает новую сеть, а контейнеры остаются в старой. Нужен
`depends_on: … restart: true` у приложений и обновление через
`docker compose up -d` без имени сервиса. Сейчас поможет
`docker compose up -d --force-recreate` ([подробнее](DOCKER.md#перезапуск-и-обновление-шлюза)).

### Пока VPN не работает, у контейнеров нет интернета

Так и задумано: kill switch не пускает трафик напрямую, пока mihomo не запущен (первый
старт, сбой). Если прямой доступ в это время допустим, задайте `MIHOMYAK_KILL_SWITCH=0`.

### Российские сайты плохо открываются через VPN

Некоторые российские сайты не пускают зарубежные IP. Пресет `ru-direct` отправляет
домены `.ru`, `.su`, `.рф` и российские IP напрямую, мимо VPN:
`MIHOMYAK_RULES_PRESETS=ru-direct`. По умолчанию он выключен.

### Как выбрать узел или страну?

`mihomyak select <группа> <узел>` (хватит части имени) или интерактивно в
`docker exec -it mihomyak mihomyak tui`. Чтобы узел выбирался сам, заведите группу
автопереключения в `config.toml` ([пример](../deploy/config.example.toml)). Лишние
узлы убираются через `MIHOMYAK_EXCLUDE`.

### Подписка не обновляется

`mihomyak status` показывает последнюю ошибку и время следующей попытки,
`mihomyak fetch` — полный запрос и ответ панели с вердиктом. Обновить вручную:
`mihomyak update`. Подробные логи: `MIHOMYAK_LOG=debug`.

### Как обновить mihomyak?

```sh
docker compose pull && docker compose up -d
```

Без Docker — скачайте новый архив из релизов, замените бинарник и выполните
`systemctl restart mihomyak`. Кэш подписки и устройство сохраняются.

### Как перенести VPN на другой сервер и не занять новое устройство?

Используйте тот же `MIHOMYAK_DEVICE_SEED` (или скопируйте `/data/machine-id` в
`MIHOMYAK_MACHINE_ID`) и тот же `MIHOMYAK_CLIENT`
([подробнее](DOCKER.md#устройство-и-перенос-на-другой-сервер)).

### На Raspberry Pi не работает лимит памяти контейнера

В Raspberry Pi OS memory cgroup часто выключен (`cgroup_disable=memory` в
`/proc/cmdline`). Добавьте `cgroup_enable=memory` в конец строки
`/boot/firmware/cmdline.txt` и перезагрузитесь. mihomyak работает и без этого.
